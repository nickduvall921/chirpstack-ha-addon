# Farm Base Home Assistant add-ons

Add this repository in Home Assistant under Settings > Add-ons > Add-on store > Repositories:

    https://github.com/nickduvall921/farmbase-ha-addons

## Add-ons

- **ChirpStack LoRaWAN** (`chirpstack_fb`): ChirpStack network server and gateway bridge, set up for US915 sub-band 2. Uses the Mosquitto broker add-on. See [chirpstack_fb/DOCS.md](chirpstack_fb/DOCS.md).
